# Post-MVP expansion gate (MAST-41–43)

The roadmap keeps future capabilities visible without implementing them in the first release.

## Rule

No expansion ships until:

1. A **concrete user-reviewed use case** exists.
2. A **plantool decision or feature ticket** captures scope, auth, and ownership.
3. MVP acceptance (M5) stays green.

## Deferred candidates

| ID | Topic | Status |
| --- | --- | --- |
| MAST-42 | MCP connectors + remote A2A | Deferred; ACP remains the worker boundary |
| MAST-43 | Proactive work, more workers, richer UI | Deferred; split into bounded tasks after pilot |

## Protocol note

MCP and A2A are not interchangeable with ACP. Evaluate only when a demonstrated interoperability gap exists (see MAST-42 description in plantool).
